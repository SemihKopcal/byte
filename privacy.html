BYTE

Privacy Policy

Last updated 13 November 2026

BYTE is a short-form video channel about AI tools. This page describes the private publishing tool behind it. The tool has no users, no sign-up and no public interface. It is operated by one person, Semih Kopcal, and it publishes his own videos to his own accounts.

What BYTE accesses

BYTE connects to three platforms, each only to the operator's own account:

  • YouTube (Google). One OAuth scope: youtube.upload. It allows uploading videos to the operator's own channel. BYTE does not read analytics, comments, subscribers or profile data.
  • Instagram (Meta). The Instagram API for publishing Reels to the operator's own professional account (@byte_knows). BYTE also reads the account name, the publishing quota and the link of the post it just published. It does not read messages, comments, followers or insights.
  • TikTok. TikTok Login Kit and the Content Posting API with the scopes user.info.basic and video.upload. The operator signs in once with his own account, and BYTE uploads each video to that account's TikTok inbox as a draft. The operator opens the draft in the TikTok app and publishes it himself. BYTE does not post directly and does not store profile information.

What is stored, and where

  • The access tokens for the three platforms are stored as encrypted GitHub Actions secrets.
  • Video scripts and the tool's code are kept in a source-code repository. Rendered video files are kept in private cloud storage, not in the repository. For Instagram publishing, BYTE creates a short-lived link so that Meta can fetch the video file.
  • Temporary build artifacts are deleted after two days.
  • A list of published video titles and IDs is kept so that the same video is not uploaded twice.

What BYTE does not do

  • It does not collect data about viewers or visitors. This site runs no analytics and sets no cookies.
  • It does not sell data, share it with advertisers, or use it to train machine-learning models.
  • It does not send data anywhere except to the platform it is publishing to, at the moment of publishing.

Revoking access and deleting data

The operator can revoke BYTE's access at any time from each platform's own settings: Google's permissions page, Instagram's apps and websites settings, and TikTok's app permissions settings. Revoking access invalidates the stored token. Because BYTE holds no data about other people, there is nothing further to delete. If you believe BYTE holds data about you, write to the address below and it will be removed.
