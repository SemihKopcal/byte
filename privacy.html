Privacy Policy

BYTE publishing tool · last updated 3 November 2026

Summary

BYTE is a private, single-user tool that uploads videos to one YouTube channel: the channel owned by the person who runs it. It has no sign-up, no other users, and no public interface. It does not collect personal information from anyone.

Who operates it

Semih Kopcal, reachable at semihkopcal1@gmail.com. There is no company behind this; it is a personal project.

Google data the tool accesses

The tool requests a single OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload

This scope allows one action: uploading a video file to the authorizing account's own YouTube channel. The tool does not read the channel's analytics, subscriber list, comments, watch history, email address or profile, because that scope does not grant access to any of them.

What is stored, and where

  • OAuth refresh token — stored as an encrypted GitHub Actions secret in a private repository, readable only by the repository owner. It is never written to logs or to any file.
  • Video files and scripts — stored in that same private repository and in temporary build artifacts that are deleted after two days.
  • A list of published video titles and IDs — kept so the tool does not publish the same video twice.

Nothing is stored on any third-party server beyond GitHub (which hosts the code and runs the scheduled job) and YouTube (which receives the uploaded video).

What is not done

  • No data is sold, rented or shared with advertisers.
  • No data is transferred to anyone except Google, as part of the upload itself.
  • No analytics, cookies or trackers run on this website.
  • No personal data is used to train any machine learning model.

Limited Use

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions. Revoking it invalidates the stored refresh token immediately and the tool stops being able to upload.

Retention

The refresh token is kept until it is revoked or deleted from the repository's secrets. Build artifacts are deleted after two days by configuration. Published videos remain on YouTube until deleted there.

Changes

If this policy changes, the date at the top of this page changes with it.
